# Synthetic runtime boundary

The first implementation deliberately refuses startup outside synthetic mode. Local JWTs are signed by a development secret, backed by server-side membership and assignments; they are not production identity. A real pilot needs an approved identity provider, deployment and model/data decisions first.

The local stack uses PostgreSQL 17 + pgvector and MinIO. Deterministic extraction retains source sentences as attributed assertions rather than pretending to understand arbitrary clinical notes. Deterministic hash embeddings are a retrieval plumbing baseline, not semantic or clinically validated embeddings. These limits must appear in demo and evaluation output.
